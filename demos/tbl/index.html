TBL

Each lane picks any element of an eight-entry table — out of range gives zero.

Types: 32-bit float elements throughout; the indices in z3.s select whole elements. Drawn at SVL = 128 bits, so the two-register table holds 8 entries; at SVL = 512 it holds 32, and out-of-range still zeroes.

Reading the picture

  1. Any element, any lane

    The table is two consecutive vectors — eight .s entries here, numbered 0 to 7. Each index lane picks one entry; the order can be arbitrary, reversed, or duplicated.

  2. Out of range means zero

    An index of 8 or more writes 0 into that lane. The zeroing is by design, so missing entries need no masking — lane 1 here reads 8, lane 3 reads 9.

  3. Not length-agnostic

    Unlike the rest of SVE, the table size depends on the vector length: code that hard-codes eight entries works only at 128 bits. That rarity is why these index lanes run up to 9.

This pass looks up z3.s = {1, 8, 3, 9} in the table {5, 2, 9, 7} + {4, 8, 1, 6}.
