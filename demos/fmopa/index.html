Reading the picture

  1. Outer product, then add

    For each row i and column j the instruction does ZA[i, j] += z0.s[i] × z1.s[j]. It accumulates. It does not wipe the tile first. Lanes are numbered from 0.

  2. Predicates

    p0/m governs rows, one lane for each element of z0.s. p1/m governs columns, one lane for each element of z1.s. The tile element changes only when both lanes are active; otherwise /m leaves it as it was. Click a predicate bit to switch that lane off and watch it happen.

  3. Why 4×4

    za.s[w11, 0] names the single-precision ZA tile selected by W11 plus offset 0. Drawn at a streaming vector length of 128 bits, a .s vector has four lanes and that tile is 4×4.

  4. On real hardware

    FMOPA accumulates in single precision with rounding, and it is one instruction: every active pair is multiplied and added in the same step. This page uses small integers so every value stays exact and readable.

This pass uses z0.s = {1, 2, 3, 4} and z1.s = {2, 1, 3, 1}.
