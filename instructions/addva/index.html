12 / SME · vertical broadcast

ADDVA

One vector runs down every active column of the ZA tile.

Types: 32-bit integer — the z0.s lanes and the 4 × 4 za0.s tile are all 32-bit containers. ADDVA's .s class is the integer form (its .d twin is the 64-bit integer variant); ADDVA has no floating-point form. Drawn at SVL = 128 bits; at SVL = 512 the tile is 16 × 16 and one vector still lands in every column.

Reading the picture

  1. Down every column

    For each active pair, ZA[i, j] gains z0.s[i]: the vector is added to every vertical slice that the column predicate allows. The value depends on the row, and it is the same in every column. One instruction, a whole-tile update.

  2. Two predicates, like ADDHA

    p0/m governs rows and p1/m governs columns — the same shape as ADDHA. There the column picks the value; here the row does, and it is the same in every column. p1 lane 2 starts off, so column 2 holds still.

  3. ADDHA is the twin

    ADDHA is the horizontal twin: ZA[i, j] gains z0.s[j], so the vector runs along every active row instead of down every column. Play ADDHA
